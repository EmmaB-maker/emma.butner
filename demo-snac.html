📋 Study Instructions

This is a simplified demo of what participants experience in this experiment.

  1. Math problem — a simple addition equation appears for 3 seconds. Be ready!
  2. Image — an image appears on screen for a few seconds. Watch carefully.
  3. Math answer — two possible answers appear. Click the correct one.
  4. Time reproduction — click the ⌛ to start timing, then click again to stop. Recreate how long the image was shown.
  5. Vastness rating — drag the slider (0-100) to rate how vast the image felt.
⚠️ When viewing the image, please don't count or use time-keeping strategies. Just observe naturally.
📐 Vastness definition: when a space seems to extend to very far distances, seemingly without limit.

📖 About the Real Study

Math: The equations are simply used as a distraction to make counting more difficult.

Images: The images you saw are highly simplified emojis. We used a validated database to select images of high-arousal nature, high-arousal urban, low-arousal nature, and low-arousal urban, all randomly depicted. Participants see 60 images.

Vastness: While not heavily used in this demo, we will analyze this data to better understand what makes up vastness and how the vastness of an image can alter our perceived time for how long it was shown.

✨ Fun fact: I coded this project using PsychoPy!
